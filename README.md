## Asignaturas

- IP — Inglés Profesional
- DT — Documentación Técnica
- SDMYR — Sistemas de Medida y Regulación
- II — Informática Industrial
- SENEH — Seguridad y Prevención
- IPLEI — Instalaciones de PLC e Interfaces
- SSP — Sistemas Secuenciales Programables
- SDP — Sistemas de Distribución de Potencia
- ADIPLE — Automatización y Digitalización Industrial
